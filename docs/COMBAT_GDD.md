## 1. 设计目标

### 核心数值目标

| 目标 | 数值 |
|------|------|
| 正常阵型下预期 TTK | **18–20 秒** |
| 加时赛触发时间 | **30 秒** |
| 超时平局时间 | **45 秒** |
| 战斗 Tick 间隔 | **100 ms**（固定步进） |
| 加时赛伤害上限 | **+70%**（7 秒加时后达到） |
| 治疗下限 | **−70%**（即 30% 效果）|

### 角色定位设计原则

```
TANK（坦克）   = 极高HP / 极低输出  ← 肉盾，靠治疗续航
ADC（远程输出）= 极低HP / 极高输出  ← 玻璃炮，必须保护
SUP（辅助）    = 低HP / 极低输出   ← 治疗续航，间接提供坦克生存
FTR（战士英雄）= 中HP / 高输出    ← 近身突击，需坦克开路
```

## 2. 基础伤害公式

### 2.1 普攻伤害计算链

```
Step 1 — 原始伤害计算
  rawDmg = attacker.atk
         × overtimeDmgMult      （加时赛中 ≥ 1.0，否则 = 1.0）
         × furyMult              （狂暴模式中 = 1.5，否则 = 1.0）

Step 2 — 护盾吸收（先于HP）
  absorbed = min(shield × shieldEff, rawDmg)
  shield  -= absorbed / shieldEff     （护盾值相应扣减）
  rawDmg  -= absorbed

  若 rawDmg ≤ 0 → 本次攻击被护盾完全吸收，对HP无效

Step 3 — 减伤计算并取整
  actualDmg = max(1, floor(rawDmg × (1 - damageReduction)))

Step 4 — 扣HP
  target.hp = max(0, target.hp - actualDmg)
  target.statDmgTaken += actualDmg
```

### 2.2 公式变量说明

| 变量 | 类型 | 说明 | 当前Demo值 |
|------|------|------|-----------|
| `attacker.atk` | 属性 | 攻击者的攻击力 | 见属性总表 |
| `overtimeDmgMult` | 动态 | 加时赛伤害倍率（见第8节） | 1.0 ~ 1.7 |
| `furyMult` | 状态 | Sydney大招狂暴倍率 | 1.0 / 1.5 |
| `shieldEff` | 动态 | 护盾有效系数（加时赛中递减） | 1.0 ~ 0.3 |
| `damageReduction` | 属性 | 减伤比例（当前版本全部为0） | 0.0 |
| `actualDmg` | 结果 | 最终对HP的有效伤害 | 最小值 = 1 |

### 2.3 当前版本说明

- **减伤 `damageReduction` 当前全部为 0**：所有棋子基础减伤均未设置，护盾是当前版本唯一的减伤手段
- **无暴击**：当前版本无暴击系统（「战斗之魂」圣物虽写有"暴击率+10%"，该属性未在战斗计算中实装）
- **伤害无属性抗性**：AD伤害与AP伤害均按同一公式结算，无额外魔抗/护甲属性

## 3. 攻击速度 & 冷却体系

### 3.1 攻击冷却公式

```
正常战斗：
  atkCooldown = atkSpeed × 1000  （单位：ms）

加时赛中：
  atkCooldown = (atkSpeed × 1000) / overtimeSpdMult

Sydney 狂暴模式（furyMode = true）：
  atkCooldown = atkSpeed × 1000 × 0.33   ← 攻速 ×3
```

> 注：当前版本加时赛倍率与狂暴模式**不叠加**（狂暴状态持续4秒，与加时赛可同时存在，但代码中分支独立处理）。

### 3.2 DPS 计算公式

```
理论DPS（无技能、无任何倍率）：
  DPS = atk / atkSpeed
```

### 3.3 移动冷却公式

```
正常战斗：
  moveCooldown = moveSpeed × 1000  （单位：ms）

加时赛中：
  moveCooldown = (moveSpeed × 1000) / overtimeSpdMult
```

## 4. 护盾系统

### 4.1 护盾工作机制

```
护盾吸收 = min(shield × shieldEff, incomingDamage)
护盾剩余 = max(0, shield - 护盾吸收 / shieldEff)
穿透伤害 = incomingDamage - 护盾吸收

其中 shieldEff：
  普通战斗：shieldEff = 1.0         → 护盾100%有效
  加时赛中：shieldEff = healMult    → 护盾随治疗倍率同步衰减
```

### 4.2 Blue W技能护盾值

| 来源 | 护盾量 | 说明 |
|------|--------|------|
| Blue 魔晶护盾（W）| **150** | 施加于自身 |
| Blue 魔晶护盾（W）| **150** | 施加于距离最近的队友 |

### 4.3 护盾 vs 加时赛

加时赛进行时护盾有效性线性递减：

| 加时秒数 | healMult（shieldEff） | 150护盾实际吸收能力 |
|---------|---------------------|-------------------|
| 0s（刚触发）| 1.00 | 150 |
| 1s | 0.90 | 135 |
| 3s | 0.70 | 105 |
| 5s | 0.50 | 75 |
| 7s（下限） | 0.30 | 45 |

## 5. 治疗系统

### 5.1 治疗公式

```
每次治疗量 = max(1, floor(healAmount × healMult))

其中 healMult：
  普通战斗：1.0
  加时赛中：max(0.30, 1.0 - floor(overtimeSec) × 0.10)

治疗目标：己方存活棋子中 hp/maxHp 比例最低者
触发条件：healCooldown ≤ 0
触发后：healCooldown 重置为 healInterval
```

### 5.2 治疗者属性

| 棋子 | 每次治疗量 | 治疗间隔 | 正常战斗每秒治疗 | 加时赛最低每秒治疗 |
|------|-----------|---------|----------------|-----------------|
| 圣愈者（己方）| 42 HP | 3000 ms | **14.0 HPS** | 4.2 HPS（healMult=0.3）|
| 暗影祭司（敌方）| 44 HP | 3000 ms | **14.7 HPS** | 4.4 HPS |

### 5.3 治疗对TTK的实际影响

圣愈者治疗坦克的等效HP：
```
治疗等效HP（正常战斗30s内）= 14.0 HPS × 30s = 420 HP
相当于护盾卫(1500HP)增加28%有效血量
```

## 6. 蓝条 & 技能触发

### 6.1 蓝条公式

```
mana += manaPerAtk      （每次发动普攻后）
mana  = min(mana, maxMana)

触发条件：mana >= maxMana  AND  wCooldown <= 0
触发后：  mana = 0,  wCooldown = skill.cooldown
```

### 6.2 英雄蓝条参数

| 英雄 | maxMana | manaPerAtk | 触发所需攻击次数 | 首次触发时间 |
|------|---------|-----------|----------------|------------|
| 布鲁 Blue | 90 | 22 | ⌈90÷22⌉ = **5次** | 5 × 1.60s = **8.0s** |
| 西德尼 Sydney | 80 | 26 | ⌈80÷26⌉ = **4次** | 4 × 1.00s = **4.0s** |

> 注：⌈x⌉ 表示向上取整。mana每攻击叠加，第N次攻击后 mana = N × manaPerAtk（超出则截断至maxMana）。

### 6.3 W技能冷却

| 英雄 | W技能冷却 | 冷却期间攻击次数（估算） |
|------|---------|----------------------|
| Blue（魔晶护盾） | 9000 ms | 9.0s ÷ 1.60s ≈ 6次（重新攒满约5次后再触发）|
| Sydney（急袭斩） | 8000 ms | 8.0s ÷ 1.00s = 8次（重新攒满约4次后再触发）|

## 8. 加时赛倍率系统

### 8.1 触发条件

```
触发时间点：elapsedMs >= 30000 ms（战斗开始30秒）
平局判定：  加时赛持续 >= 15000 ms（总时间45秒）
```

### 8.2 倍率公式

```
overtimeSec = (elapsedMs - 30000) / 1000   （加时进行秒数）

伤害/攻速倍率：
  overtimeDmgMult = min(1.70, 1.0 + floor(overtimeSec) × 0.10)

治疗/护盾倍率：
  healMult = max(0.30, 1.0 - floor(overtimeSec) × 0.10)
```

> `floor(overtimeSec)` 表示每整秒档位才变化一次，而非连续变化。

### 8.3 倍率进程表

| 加时时间 | 总时间 | 伤害倍率 | 治疗倍率 | ADC实际DPS（原76.9）| 坦克护盾吸收（150）|
|---------|-------|---------|---------|---------------------|-----------------|
| 0s | 30s | ×1.0 | ×1.0 | 76.9 | 150 |
| 1s | 31s | ×1.1 | ×0.9 | 84.6 | 135 |
| 2s | 32s | ×1.2 | ×0.8 | 92.3 | 120 |
| 3s | 33s | ×1.3 | ×0.7 | 100.0 | 105 |
| 4s | 34s | ×1.4 | ×0.6 | 107.7 | 90 |
| 5s | 35s | ×1.5 | ×0.5 | 115.4 | 75 |
| 6s | 36s | ×1.6 | ×0.4 | 123.1 | 60 |
| **7s** | **37s** | **×1.7（上限）** | **×0.3（下限）** | **130.7** | **45** |
| 8s–15s | 38s–45s | ×1.7 | ×0.3 | 130.7（保持）| 45（保持）|

### 8.4 加时赛对局势的影响分析

```
加时赛前（0s）：
  玩家总DPS ≈ 269，治疗14.0 HPS → 净进攻DPS ≈ 269
  敌方总DPS ≈ 372，治疗14.7 HPS → 净进攻DPS ≈ 372

加时赛第7s后（倍率锁定）：
  玩家总DPS ≈ 269 × 1.7 ≈ 457，治疗14.0 × 0.3 ≈ 4.2 HPS
  敌方总DPS ≈ 372 × 1.7 ≈ 632，治疗14.7 × 0.3 ≈ 4.4 HPS

→ 敌方DPS优势（1.38×）在加时赛中被保留，双方同等倍率下敌方仍略强
→ 但玩家英雄技能（护盾/狂暴）在加时赛中的价值大幅提升
→ 设计意图：拖入加时赛通常对玩家不利，刺激玩家进攻
```

## 10. DPS & TTK 推导

### 10.1 基础公式

```
DPS（每秒伤害）= ATK / atkSpeed
TTK（击杀耗时）= 目标总HP / 己方总DPS
```

### 10.2 玩家视角 TTK（消灭全体敌人）

```
敌方总HP = 650×3 + 1600×2 + 620 = 1950 + 3200 + 620 = 5770 HP

玩家总DPS（理想战斗，全部攻击敌方）：
  = 15.0 + 70.0 + 76.9 + 76.9 + 20.0 + 10.0
  = 268.8 DPS

简单TTK = 5770 / 268.8 ≈ 21.5 秒

实际TTK更短原因：
  1. 圣愈者辅助攻击贡献（治疗降低了敌方对己方的有效输出，使前排坦克更久）
  2. Sydney W急袭斩 + 大招额外输出
  3. 初始阵型中ADC先接触较脆的射手而非坦克
  4. Blue大招160×2~3命中额外约320~480输出
```

### 10.3 敌方视角 TTK（消灭己方）

```
己方总HP = 1520 + 750 + 650 + 650 + 1500 + 550 = 5620 HP

敌方总DPS：
  = 102.9×3 + 27.1×2 + 9.0
  = 308.8 + 54.3 + 9.0
  = 372.1 DPS

简单TTK = 5620 / 372.1 ≈ 15.1 秒

实际TTK更长原因：
  1. 圣愈者持续治疗（等效+420HP over 30s）
  2. Blue护盾吸收（每次W覆盖2个目标各150HP）
  3. 坦克吸引仇恨，ADC得以安全输出
```

### 10.4 平衡性评估

```
理论DPS比（敌/己）= 372.1 / 268.8 = 1.38
→ 敌方原始输出比玩家高38%

补偿机制：
  圣愈者持续治疗：+14 HPS
  Blue护盾W：每9s提供300总护盾（等效 33.3 HPS）
  合计辅助效果：约47 HPS

等效调整后玩家方净血量消耗速度：
  净受伤速度 = 372.1 - 47 = 325.1 DPS
  
调整TTK（己方）= 5620 / 325.1 ≈ 17.3 秒 ← 接近设计目标18s ✓
```
